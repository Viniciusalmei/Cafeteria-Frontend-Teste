# Grão & Prosa – Sistema de Cafeteria

Sistema web desenvolvido para o gerenciamento de produtos de uma cafeteria.

### Funcionalidades
- Login de acesso ao sistema.
- Cadastro de produtos.
- Edição de produtos.
- Remoção de produtos.
- Consulta e pesquisa de produtos.
- Visualização de informações do estoque.
